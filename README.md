# Crisol: Theater of Idols 한국어 패치

*Crisol: Theater of Idols*의 게임 텍스트를 한국어로 번역한 패치입니다. AI 번역을 바탕으로 원문 대조와 교정을 진행했으며, 현재 **2,848개 번역 항목**을 반영했습니다.

## 적용 내용

- 메뉴, 설정, 목표, 조작 안내
- 챕터별 대사와 자막
- 아이템, 기술, 문서, 일지, 경전
- 제작진 역할명과 모델 감상실의 일부 표시명
- 주요 표시 글꼴의 한글 지원
- 기존 `English` 항목의 표시 이름을 `한국어`로 바꾸는 설정

## 설치 방법

1. 아래 원본 파일을 **게임 설치 폴더 밖에 백업 또는 삭제**합니다.
   ```
   CRToiPrototype/Content/Paks/CRToiPrototype-Windows.pak
   ```
2. 패치 압축을 풀고, 포함된 `CRToiPrototype` 폴더를 게임 설치 폴더에 복사하여 덮어씁니다.
3. 게임 표시 언어에서 **한국어**를 선택합니다. 표시 이름이 `English`로 남아 있다면 해당 항목을 선택하세요.

이전 버전의 한국어 패치를 사용 중이라면 최신 패치로 다시 덮어쓰면 됩니다.
