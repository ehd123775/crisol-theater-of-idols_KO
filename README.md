# Crisol: Theater of Idols 한국어 패치


*Crisol: Theater of Idols*의 게임 텍스트를 한국어로 번역한 비공식 패치입니다. AI 번역을 바탕으로 원문 대조와 교정을 진행했으며, 현재 **2,848개 번역 항목**을 반영했습니다.

원본 게임 파일 옆에 `CRToiPrototype-Korean_P.pak` 하나를 추가하는 방식입니다. **원본 `.pak`, `.ucas`, `.utoc` 파일은 교체하지 않습니다.**

## 적용 내용

- 메뉴, 설정, 목표, 조작 안내
- 챕터별 대사와 자막
- 아이템, 기술, 문서, 일지, 경전
- 제작진 역할명과 모델 감상실의 일부 표시명
- 주요 표시 글꼴의 한글 지원
- 기존 `English` 항목의 표시 이름을 `한국어`로 바꾸는 설정

영어 텍스트 슬롯을 한국어로 바꾸며, **음성은 영어로 유지됩니다.**

## 설치 방법

1. `Crisol_KO_v0.5_P.zip`의 압축을 풉니다.
2. 포함된 `CRToiPrototype` 폴더를 게임 설치 폴더에 복사합니다.
3. 아래 위치에 패치 파일이 추가되었는지 확인합니다.

   ```
   게임 설치 폴더/CRToiPrototype/Content/Paks/CRToiPrototype-Korean_P.pak
   ```

6. 게임 표시 언어에서 **한국어**를 선택합니다. 표시 이름이 `English`로 남아 있다면 해당 항목을 선택하세요.

패치 파일 이름의 `_P.pak`을 유지하세요.

## 업데이트와 제거

- **업데이트:** 기존 `CRToiPrototype-Korean_P.pak`을 새 버전의 같은 파일로 교체합니다.
- **제거:** 추가한 `CRToiPrototype-Korean_P.pak` 파일만 삭제합니다.
